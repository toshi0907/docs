## 質問

シェルスクリプト（bash）で、コマンドの実行結果を配列に格納するにはどうすればよいですか。

## 回答

bashでコマンドの実行結果を配列に格納する方法はいくつかありますが、代表的なものを紹介します。

### `mapfile`（`readarray`）を使う方法（推奨）

bash 4.0以降では、`mapfile`（別名`readarray`）を使うのが最も確実です。コマンドの出力を1行ずつ配列の要素に格納できます。

```bash
# コマンド結果を1行1要素として配列に格納
mapfile -t lines < <(ls /var/log)

echo "要素数: ${#lines[@]}"
for line in "${lines[@]}"; do
    echo "行: $line"
done
```

- `-t` オプションを付けることで、各要素の末尾の改行文字を取り除きます
- `<(command)` はプロセス置換で、コマンドの標準出力をファイルのように扱えます。パイプ（`command | mapfile -t lines`）を使うと、`mapfile`がサブシェルで実行されて配列が呼び出し元のシェルに反映されないため、プロセス置換を使うのがポイントです

### `read -a` を使う方法

1行の出力を空白区切りで配列に格納したい場合は、`read -a` を使えます。

```bash
# 空白区切りの1行を配列に格納
read -a words <<< "$(echo apple orange banana)"

echo "${words[0]}"  # apple
echo "${words[@]}"  # apple orange banana
```

こちらは行ではなく単語（IFSによる区切り）単位で配列に入る点に注意してください。

### `arr=($(command))` を使う簡易な方法

```bash
# 簡易だが単語分割・グロブ展開に注意が必要
files=($(ls *.txt))
```

もっとも短く書けますが、`command`の出力がクォートなしで単語分割・パス名展開（グロブ）の対象になるため、要素にスペースを含むファイル名などがあると意図しない分割が発生します。可能な限り`mapfile`を使うことをおすすめします。

### まとめ

| 方法 | 区切り単位 | 必要なbashバージョン | 特徴 |
|------|-----------|----------------------|------|
| `mapfile -t arr < <(command)` | 行 | 4.0以降 | 最も安全でおすすめ |
| `read -a arr <<< "$(command)"` | 空白（単語） | 全バージョン | 1行の単語分割に向く |
| `arr=($(command))` | 空白（単語） | 全バージョン | 手軽だが単語分割・グロブに注意 |

シェルスクリプトの配列全般については [シェルスクリプトリファレンス](shellscript.html#配列) も参照してください。
